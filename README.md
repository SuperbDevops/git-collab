# <shared_repo>

협업 실습용 공유 저장소.

## 참여 방법

```bash
git clone https://github.com/<org_name>/<shared_repo>.git
cd <shared_repo>
```

`members` 폴더에 `<본인이름>.md` 를 추가.

## main 브랜치

`main` 에는 직접 전송이 불가.

```
remote: error: GH006: Protected branch update failed
remote: error: Changes must be made through a pull request.
```

브랜치를 생성해 작업한 뒤 Pull Request 로 요청.

## 주의

이 저장소는 **공개 상태**.
연락처나 실명 등 공개를 원하지 않는 정보를 기재하지 않음.
반영된 내용은 이력에 잔존하므로 삭제해도 완전히 제거되지 않음.
